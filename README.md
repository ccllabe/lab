# Chi-Ching Lee's Lab

長庚大學資訊工程學系李季青實驗室的 GitHub Pages 網站。這個版本把原本分散在三個網站的內容重新整理成可維護的靜態網站：

- 實驗室與老師介紹：[`index.html`](index.html)
- 成員與校友：[`members.html`](members.html)
- 課程與教材入口：[`courses.html`](courses.html)
- 大數據分析積木微學程：[`micro-course.html`](micro-course.html)
- 研究服務與開源專案：[`services.html`](services.html)
- 實驗室生活與校園位置：[`life.html`](life.html)

## GitHub Pages

在 GitHub repository 的 **Settings → Pages** 選擇 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`，即可使用：

`https://ccllabe.github.io/lab/`

網站不需要建置工具，直接由 GitHub Pages 提供 HTML、CSS、JavaScript 與 `assets/` 靜態資產。
